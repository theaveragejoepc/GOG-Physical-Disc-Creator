# Contributing

Open an issue with reproducible steps before proposing a large change. Keep patches focused, preserve upstream attribution, and do not add credentials, commercial game files or unlicensed artwork.

Follow [BUILDING](docs/BUILDING.md), run the self-tests, and describe any manual verification in your pull request. UI changes should include a screenshot using placeholder artwork. Explain limitations rather than claiming hardware/account tests you did not perform.

Contributions to the application are submitted under its existing GPL version 3 license; retain separate third-party notices where applicable. Do not change LICENSE or remove attribution in routine changes.
