# Security reporting

Do not post credentials, API keys, GOG authentication files, or exploit details affecting other users in public issues. Use GitHub's private vulnerability reporting if this repository offers it. Otherwise open a minimal issue requesting a private reporting channel without sensitive details.

No response-time guarantee or formal security audit is claimed. The current preview is the maintenance target; older embedded disc launchers do not update automatically. Verify release checksums and use source/binaries from the intended repository.
