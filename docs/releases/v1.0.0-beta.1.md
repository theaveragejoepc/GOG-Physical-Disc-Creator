# GOG Physical Disc Creator 1.0.0-beta.1

First public preview of this independent GPL-3.0 derivative of east35/GOG-Disc-Packager, with TargetFill padding adapted under MIT.

Includes ordered patches/DLC with Skip, a tabbed creator, local/SteamGridDB artwork, a dark cover grid, direct DOSBox-aware launching, XInput navigation, centered backgrounds, Keep launcher open by default, and the ISO-eject fix.

Download the Windows x64 ZIP and extract the entire folder. Run `GOG Physical Disc Creator.exe` with `LauncherPayload` alongside it. The accompanying source ZIP corresponds to this tag; licenses and third-party notices are included.

This is an unsigned preview. Collections are single-disc. Physical-disc and physical-controller validation remains outstanding; see README and CHANGELOG. Existing ISOs must be rebuilt to receive the new embedded launcher. No games, API key or GOG account credentials are included.
